# LLM Wiki approach provenance

Source: [Andrej Karpathy, LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f#file-llm-wiki-md), read 2026-10-10. This is an implementation inspiration, not evidence of application behavior.

The approach keeps original materials separate from a linked Markdown knowledge layer, with agent instructions governing upkeep. It calls for ingestion, cited answers, periodic maintenance, an index and chronological log.

Here, existing repository docs/code supply the sources; wiki/ holds project synthesis. Root and wiki AGENTS.md connect future work to the maintenance workflow. Summaries retain provenance and distinguish old milestones from current implementation. No application retrieval service is added.
